DESIGN SOCKS V6.8.2 배포 안내

적용 내용
1. 전량품절·일부품절 주문도 피킹수량과 품절수량의 합이 주문수량과 같으면 출고완료할 수 있습니다.
2. 품절수량 처리는 끝났지만 검증상태 표시가 누락된 주문은 출고완료 시 서버가 최종검증을 이어서 처리합니다.
3. I 포장완료/I 피킹완료 버튼은 피킹수량이 남아 있어도 관리자가 확인창을 거쳐 누를 수 있습니다.
4. 강제 I 완료 시 미피킹 품번 수를 확인창에 표시하며, 남은 수량을 임의로 품절 전환하지 않습니다.
5. 실제 출고완료는 미처리 수량이 있으면 계속 차단하여 재고·매출 오류를 방지합니다.

DB 적용
1. Supabase SQL Editor를 엽니다.
2. SQL/V6.8.2-SOLDOUT-SHIPPING-COMPLETE.sql 전체를 실행합니다.
3. 'V6.8.2 품절 포함 출고완료 적용 완료' 결과를 확인합니다.

배포 명령
git add .
git commit -m "release v6.8.2 allow soldout shipping and flexible I completion"
git push origin main

배포 후 Ctrl+F5를 누르고 좌측 아래 V6.8.2 표시를 확인하세요.
