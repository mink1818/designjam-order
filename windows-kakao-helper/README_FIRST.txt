DESIGN SOCKS 카톡 찾기 V6.7.82 키보드 채팅검색 전용판

1. PC 카카오톡을 설치하고 로그인합니다.
2. 1_INSTALL_KAKAO_HELPER.bat 파일을 한 번 실행합니다.
3. 설치 완료창이 나오면 2_TEST_DIRECT.bat을 실행해 직접 작동을 확인합니다.
4. 정상 작동하면 ERP 주문관리 또는 거래명세서에서 '카톡 찾기'를 누릅니다.
5. 브라우저가 외부 프로그램 실행을 물으면 허용합니다.
6. 카카오톡 검색 결과를 사람이 확인합니다.

안전 원칙
- 자동 메시지 전송 없음
- 자동 대화방 선택 없음
- Enter 입력 없음
- 마우스 클릭·화면 좌표 사용 없음
- 기존 DESIGN SOCKS 스캐너와 독립 실행

검색명이 다른 거래처는 ERP 거래처관리에서 '카카오톡 검색명'을 저장하세요.
검색명은 저장된 카카오톡 검색명, 대표자명, 거래처명 순서로 사용합니다.
