DESIGN SOCKS 카톡 찾기 V6.7.61

1. PC 카카오톡을 설치하고 로그인합니다.
2. 1_INSTALL_KAKAO_HELPER.bat 파일을 한 번 실행합니다.
3. ERP 주문관리 또는 거래명세서에서 '카톡 찾기'를 누릅니다.
4. 브라우저가 외부 프로그램 실행을 물으면 허용합니다.
5. 카카오톡 검색 결과를 사람이 확인합니다.

안전 원칙
- 자동 메시지 전송 없음
- 자동 대화방 선택 없음
- Enter 입력 없음
- 화면 좌표 클릭 없음
- 기존 DESIGN SOCKS 스캐너와 독립 실행

검색명이 다른 거래처는 ERP 거래처관리에서 '카카오톡 검색명'을 저장하세요.
비어 있으면 ERP 거래처명이 자동으로 사용됩니다.
