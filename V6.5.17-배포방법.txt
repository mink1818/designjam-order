DESIGN SOCKS V6.5.17 배포 안내

핵심 수정
- 거래처별 단가 기준을 정규화된 거래처명 최신단가로 고정
- 같은 상호로 가입된 중복 거래처 계정 ID 전체에 동일 단가 재동기화
- 거래처 본인 상품목록·상세·장바구니·주문 저장에 전용단가 우선 적용
- 관리자 대신주문의 등록 거래처·직접입력 거래처 모두 동일 기준 적용
- 거래명세서와 관리자 주문화면은 주문 저장 당시 확정된 전용단가 사용
- 단가표를 갱신해도 이미 접수된 주문·거래명세서의 주문 당시 단가는 변경하지 않음
- 전용단가가 없는 거래처와 품번만 기본단가 사용
- 끝에 A·M이 붙는 품번은 기본 품번과 충돌하지 않을 때 A·M을 생략해도 자동 인식
- 같은 기본 품번의 A·M 후보가 둘 이상이면 오인식하지 않고 정확한 품번 입력 유지
- V6.5.16까지의 피킹메모·연속 바코드 출력·대신주문 수량 인식 기능 포함
- 버전 및 PWA 캐시 V6.5.17 갱신

중요 보호 기준
- customer_name_item_prices의 거래처명 단가가 운영 기준입니다.
- customer_item_prices의 계정 ID 단가는 호환용 복사본입니다.
- 이후 기능 추가 시 ID 단가가 거래처명 단가보다 우선하도록 변경하면 안 됩니다.
- orders.price는 주문 접수 당시 확정값이며 이후 단가표 갱신으로 바꾸면 안 됩니다.
