DESIGN SOCKS V6.5.29 배포 순서

이번 수정은 화면·JavaScript 변경입니다.
추가 SQL 실행과 Supabase Function 재배포는 필요하지 않습니다.

1. 기존 프로젝트에 V6.5.29 파일을 덮어씁니다.
2. 터미널에서 아래 명령을 실행합니다.

git add .
git commit -m "release v6.5.29 delivery preview and proxy owner fix"
git pull --rebase origin main
git push origin main

3. 배포 후 PC는 Ctrl+F5, 모바일은 앱 또는 브라우저를 완전히 종료한 뒤 다시 실행합니다.

적용 내용
- 주문카드를 펼치기 전 납품처명 즉시 표시
- 관리자 대신주문에서 관리자 이름이 대표자명으로 저장·표시되는 현상 방지
- 등록 거래처의 실제 대표자명은 유지
- 거래처별 단가와 주문 당시 저장 단가는 변경하지 않음
