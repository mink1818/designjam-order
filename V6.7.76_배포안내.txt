DESIGN SOCKS V6.7.76 배포 순서

1. Supabase SQL Editor에서 다음 파일을 열고 전체 실행
   SQL/V6.7.76-STATEMENT-SHIPMENT-ENTRY.sql

2. 프로젝트 폴더에서 기존과 동일하게 배포
   npx vercel --prod

3. 브라우저에서 Ctrl+Shift+R로 강력 새로고침

확인 항목
- 상품목록에서 8881, 8882만 10,000원 / 10개 묶음으로 표시
- 관리자 거래명세서 표에서 8881, 8882는 죽이 아닌 실제 개수와 10개 묶음 단가로 표시
- 거래명세서 하단에 운송장 직접 등록·사진 보내기 영역 표시
- 운송장 저장 또는 송장사진 선택 후 등록 가능
- 등록된 사진의 사진 복사 버튼으로 카카오톡에 붙여넣기 가능

주의
- V6.7.74 송장관리 SQL이 먼저 적용되어 있어야 합니다.
- 기존 orders 데이터와 기존 주문금액은 변경하지 않습니다.
