DESIGN SOCKS V6.5.32 배포

1. Supabase SQL Editor에서 아래 파일 전체 실행
   SQL/V6.5.32-SECURITY-DELIVERY.sql

2. 관리자 계정 관리 Edge Function 재배포
   npx supabase functions deploy admin-user-management

3. Git 배포
   git add .
   git commit -m "release v6.5.32 security delivery destinations"
   git pull --rebase origin main
   git push origin main

4. 배포 후 PC: Ctrl+F5 / 모바일: 브라우저 완전 종료 후 다시 실행

주의
- git pull --rebase 중 충돌이 표시되면 push를 반복하지 말고 충돌을 먼저 해결해야 합니다.
- 거래처별 단가 테이블과 주문 저장 단가 계산 코드는 이번 버전에서 변경하지 않았습니다.
