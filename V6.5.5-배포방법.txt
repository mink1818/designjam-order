DESIGN SOCKS V6.5.5 배포 방법

1. Supabase SQL Editor에서 아래 파일 전체 실행
SQL/V6.5.5-DIRECT-CUSTOMER-NAME-PRICE.sql

2. 웹 배포 후 상품관리에서 거래처별 단가 엑셀을 다시 한 번 등록
   - 가입 거래처: 고객 ID 전용단가 저장
   - 미가입·직접입력 거래처: 거래처명 전용단가 저장

상품 구조 변경 방법
- 상품관리에서 엑셀 파일 선택
- "엑셀 동기화 (추천)" 선택
- "선택한 방식으로 실제 반영" 클릭
- 대분류·카테고리 순서와 소속이 엑셀대로 변경됩니다.
- 엑셀에서 빠진 상품·카테고리·대분류는 주문 기록 보호를 위해 삭제 대신 숨김 처리됩니다.
- 상품등록 형식의 워크시트가 여러 개이면 모든 시트를 합쳐 반영합니다.

신규 상품·사진 추가 방법
- 새 사진을 사진 보관함에 먼저 등록합니다.
- 엑셀에 신규 행 또는 신규 상품등록 시트를 추가합니다.
- 엑셀을 읽은 뒤 미리보기에서 신규 행·사진 연결을 확인합니다.
- 기본 선택된 "엑셀 동기화 (추천)"로 실제 반영합니다.
- 같은 파일명으로 사진을 교체해도 새 사진이 보이도록 캐시 주소를 자동 갱신합니다.

대분류 대표사진 삭제
- 상품관리 > 등록된 대분류 > 해당 사진 아래 "대표사진 삭제"
- 대분류와 하위 상품은 유지되고 대표사진만 삭제됩니다.

3. 터미널
git add .
git commit -m "release v6.5.5 direct customer name price"
git push

4. 배포 완료 후 브라우저 Ctrl+F5

확인 예시
- 관리자 대신주문 > 거래처 직접 입력 > 두인양말
- 화면에 "직접입력 전용단가 ...개 적용 중" 표시 확인
- 품번 1 입력 시 엑셀의 두인양말 단가 적용 확인

Functions 재배포는 필요 없습니다.
