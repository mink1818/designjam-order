DESIGN SOCKS V6.7.88 배포 안내

이번 버전은 송장 자동인식·자동매칭·고객 배송조회 기능을 제거하고
출고전달에서 주문별로 송장사진을 직접 등록하는 방식으로 변경합니다.

추가로 실행할 SQL은 없습니다.
기존 송장 DB와 이미 등록한 송장사진·연결정보는 삭제하지 않습니다.

배포 명령
git add .
git commit -m "release v6.7.88 manual order shipment workflow"
git push origin main

Vercel 연결 저장소이므로 npx vercel --prod는 실행하지 않습니다.

배포 후 확인
1. 브라우저에서 Ctrl+F5로 새로고침합니다.
2. 좌측 하단 버전이 V6.7.88인지 확인합니다.
3. 관리자 메인에서 출고전달·송장등록을 엽니다.
4. 주문의 명세서·송장 전달을 누릅니다.
5. 송장사진 선택 또는 사진 복사 후 Ctrl+V로 사진을 넣습니다.
6. 출고처·택배사·운송장번호를 직접 입력하고 현재 주문에 수동 등록합니다.
7. 거래처 주문화면에 배송조회가 표시되지 않는지 확인합니다.

유지 기능
- 동일 사진 및 동일 운송장번호 중복 방지
- 주문 하나에 여러 송장 등록
- 기존 송장사진 및 긴 거래명세서 표시
- 송장 원본 31일 자동삭제
- 전달완료 및 전달완료 취소
