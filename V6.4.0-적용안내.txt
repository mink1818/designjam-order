DESIGN SOCKS V6.4.0 적용 안내

1. Supabase SQL Editor에서 아래 파일을 전체 실행합니다.
   SQL/V6.4.0-PICKING-RESET-WAREHOUSE-CUSTOMER-PRICE.sql

2. 프로젝트 파일을 Git에 올립니다.
   git add .
   git commit -m "release v6.4.0 integrated picking warehouse pricing statement"
   git push

3. 배포 완료 후 브라우저에서 Ctrl+F5를 누릅니다.

[이번 버전]
- 출고대기 일부품절·피킹수량 수정 버튼
- 검증된 피킹 초기화 시 ERP 재고 복원 후 재피킹 가능
- 거래처관리 주문내역을 거래처 ID로 정확히 조회
- 거래명세서를 묶음명+단가별로 압축 표시
- 상품 엑셀의 출고지 열(S/B/I)을 상품과 주문에 저장
- 거래처별 품번 단가(50원 단위) DB 및 거래처 주문가격 적용

[주의]
- SQL을 실행하지 않으면 피킹 초기화와 거래처별 단가 기능이 동작하지 않습니다.
- 출고대기 수량을 바꿀 때는 주문관리의 "일부품절·피킹수량 수정" 버튼을 사용합니다.
- 이 버튼은 기존 재고 차감을 먼저 복원한 후 피킹을 초기화합니다.
